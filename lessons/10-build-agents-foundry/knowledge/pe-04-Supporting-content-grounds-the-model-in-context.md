# Supporting content grounds the model in context

**Category:** grounding  
**Source:** prompt-engineering-techniques.pdf

Supporting content is information the model can use to influence its output, such as the current date, the user's name, or the user's important topics. It differs from primary content in that it isn't the main target of the task but is used alongside it. For example, giving the model a list of important topics lets it group a set of workshops by those topics instead of simply listing them.
