# Zero-shot, one-shot, and few-shot learning

**Category:** few-shot  
**Source:** prompt-engineering-techniques.pdf

Few-shot learning includes one or more examples of the desired behavior as input/output pairs, which condition the model to respond as wanted for the current inference. It isn't permanent training. Using no examples is zero-shot learning. With the Chat Completion API, few-shot examples are added to the messages array as example user/assistant interactions after the system message. Examples cleanly show the model how to operate.
