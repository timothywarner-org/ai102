# Start with clear instructions and repeat them at the end

**Category:** structure  
**Source:** prompt-engineering-techniques.pdf

The order of information in a prompt matters. Telling the model the task at the beginning, before extra context or examples, can produce higher-quality output. Models are also susceptible to recency bias, meaning information at the end of the prompt can carry more influence. Because of this, it is worth experimenting with repeating the key instructions at the end of the prompt and evaluating the impact.
